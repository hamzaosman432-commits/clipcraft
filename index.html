Questions

Is it really free?

Yes. The code is open source and the hosting is free. There is no paid tier and no watermark.

Does my video get uploaded?

No. Transcription and rendering run in your browser, so the file never leaves your device.

Which languages work?

Clipcraft uses the open-source Whisper model, which handles about 100 languages. Accuracy is highest for widely spoken ones.

How long a video can I caption?

Short clips under a few minutes work best. Longer files depend on your device's memory.

Can I edit the captions?

Click any word to fix it, then change the font, size, color, and position.
